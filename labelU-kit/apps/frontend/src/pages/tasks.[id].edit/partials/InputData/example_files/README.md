# 问答对生成功能支持的文件格式示例

## 支持的文件类型

### 1. 文本文件
- **.txt** - 纯文本文件
- **.json** - JSON格式文件
- **.csv** - CSV表格文件
- **.md** - Markdown文档

### 2. 文档文件
- **.pdf** - PDF文档 (支持OCR文字识别)
- **.doc** - Word 97-2003文档
- **.docx** - Word 2007+文档

### 3. 图片文件
- **.png** - PNG图片 (支持OCR文字识别)
- **.jpg/.jpeg** - JPEG图片 (支持OCR文字识别)

## 文件处理说明

### 文本文件处理
- 直接读取文本内容
- 解析结构化数据
- 提取文本字段

### 文档文件处理
- PDF文件：使用OCR技术提取文字
- Word文档：解析文档结构，提取文本内容

### 图片文件处理
- 使用OCR技术识别图片中的文字
- 支持手写文字识别
- 支持多语言文字识别

## 注意事项

1. 文件大小限制：单个文件不超过100MB
2. 文本文件建议使用UTF-8编码
3. 图片文件需要清晰的文字内容
4. 处理时间取决于文件大小和复杂度
