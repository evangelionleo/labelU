# 问答对生成页面

这是一个专门为问答对生成任务设计的页面，提供了PDF文档查看和问答对管理功能。

## 功能特性

### 1. PDF文档查看
- **翻页功能**：支持上一页/下一页导航
- **页码显示**：显示当前页码和总页数
- **快速跳转**：支持页码快速跳转
- **文件切换**：支持在多个文件之间切换

### 2. 问答对管理
- **添加问答对**：可以为每个页面添加新的问答对
- **编辑功能**：支持编辑问题、答案、类型和难度
- **删除功能**：可以删除不需要的问答对
- **属性设置**：
  - 问题类型：一般问题、选择题、判断题、填空题
  - 难度等级：简单、中等、困难
  - 页码关联：自动关联到当前页面

### 3. 用户界面
- **响应式设计**：支持桌面和移动设备
- **现代化UI**：使用Ant Design组件库
- **直观操作**：清晰的操作按钮和状态提示

## 使用方法

### 访问页面
页面路径：`/tasks/{taskId}/qa-generation`

### 基本操作流程
1. **查看PDF**：使用翻页按钮浏览文档内容
2. **切换文件**：使用"上一个文件"/"下一个文件"按钮
3. **添加问答对**：点击"添加问答对"按钮
4. **编辑内容**：点击"编辑"按钮修改问答对
5. **保存更改**：点击"保存"按钮保存修改
6. **删除问答对**：点击"删除"按钮移除问答对

### 快捷键支持
- 左右箭头键：翻页
- Ctrl + 左右箭头：切换文件

## 技术实现

### 组件结构
```
QAGenerationPage/
├── HeaderSection (页面头部)
├── PDFViewerContainer (PDF查看器)
│   ├── PDFCanvas (PDF内容区域)
│   └── ControlPanel (控制面板)
│       ├── NavigationButtons (翻页按钮)
│       └── FileNavigation (文件导航)
└── QAPanel (问答对管理面板)
    └── QACard (问答对卡片)
```

### 状态管理
- `currentFileIndex`: 当前文件索引
- `currentPage`: 当前页码
- `totalPages`: 总页数
- `qaList`: 问答对列表
- `loading`: 加载状态

### 样式系统
使用styled-components构建的样式系统，支持：
- 响应式布局
- 主题色彩
- 动画效果
- 移动端适配

## 配置要求

### 任务配置
页面仅对满足以下条件的任务显示：
1. 任务类型为文本类型 (`MediaType.TEXT`)
2. 包含问答对生成工具 (`qaGenerationTool`)

### 文件要求
支持的文件类型：
- PDF文档
- 文本文件
- 预标注文件

## 故障排除

### 常见问题
1. **页面不显示**：检查任务配置是否包含问答对生成工具
2. **文件无法加载**：确认文件格式和权限
3. **样式异常**：检查CSS依赖是否正确加载

### 调试信息
页面包含详细的控制台日志，可以帮助诊断问题：
- 任务配置信息
- 文件加载状态
- 用户操作记录
