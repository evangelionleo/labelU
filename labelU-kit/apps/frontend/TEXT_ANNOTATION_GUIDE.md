# 文本标注功能使用指南

## 功能概述

文本标注功能允许用户对文本内容进行问答对生成标注。用户可以选择"文本(问答对生成)"作为任务类型，上传文本文件后可以进行问答对的标注工作。

## 功能特性

### 1. 支持的文件格式
- **文本文件**: .txt, .json, .csv, .md
- **文件大小**: 单个文件不超过100MB
- **编码格式**: UTF-8

### 2. 标注工具
- **文本标注工具**: 用于标注文本内容
- **标签工具**: 用于添加标签分类

### 3. 数据格式
- **JSONL格式**: 每行一个JSON对象
- **JSON格式**: 包含samples数组的JSON文件

## 使用方法

### 步骤1：创建文本标注任务
1. 在任务大厅点击"新建任务"
2. 选择"文本(问答对生成)"作为媒体类型
3. 填写任务基本信息：
   - **任务名称**: 输入任务名称
   - **任务描述**: 可选，描述任务详情
   - **任务提示**: 可选，提供标注指导

### 步骤2：上传文本文件
1. 在文件上传区域点击或拖拽文件
2. 支持的文件格式：
   - 文本文件：.txt, .json, .csv, .md
3. 文件大小限制：单个文件不超过100MB
4. 可以批量选择多个文件

### 步骤3：配置标注工具
1. 在标注配置页面选择需要的工具：
   - **文本标注工具**: 用于标注文本内容
   - **标签工具**: 用于添加标签分类
2. 配置工具属性：
   - 设置标注字段
   - 配置选项值
   - 设置验证规则

### 步骤4：开始标注
1. 点击"创建"按钮提交任务
2. 系统会显示创建进度
3. 创建成功后可以开始标注工作

## 技术实现

### 前端组件
- `InputInfoConfig`: 任务基本信息配置
- `InputData`: 文件上传组件
- `AnnotationConfig`: 标注工具配置

### API服务
- 支持文本文件上传
- 文本内容解析和验证
- 问答对数据存储

### 文件处理
- 使用FormData进行文件上传
- 支持多种文本格式验证
- 文件大小限制检查

## 注意事项

1. **文件格式**: 只支持文本文件格式
2. **文件大小**: 单个文件不能超过100MB
3. **编码格式**: 建议使用UTF-8编码
4. **数据格式**: 支持JSONL和JSON两种格式
5. **网络连接**: 需要稳定的网络连接进行文件上传
