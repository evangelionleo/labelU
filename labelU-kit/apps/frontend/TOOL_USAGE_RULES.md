# 工具使用规则说明

## 工具分类

### 全局工具
全局工具可以在所有任务类型中使用（除了特殊限制）：

1. **标签工具** (`tagTool`)
   - 适用于：所有任务类型
   - 功能：添加标签分类

2. **文本标注工具** (`textTool`)
   - 适用于：图像、视频、音频任务
   - 功能：进行文本标注
   - **注意**：在"文本(问答对生成)"任务中不可用

3. **问答对生成工具** (`qaGenerationTool`)
   - 适用于：仅"文本(问答对生成)"任务
   - 功能：生成问答对
   - **注意**：其他任务类型不可用

### 专用工具

#### 图像任务工具
- 矩形框工具 (`rectTool`)
- 多边形工具 (`polygonTool`)
- 点标注工具 (`pointTool`)
- 线条工具 (`lineTool`)
- 立体框工具 (`cuboidTool`)
- 关联关系工具 (`relationTool`)
- 智能标注工具 (`smartAnnotationTool`)

#### 视频任务工具
- 视频截取工具 (`videoSegmentTool`)
- 视频帧工具 (`videoFrameTool`)

#### 音频任务工具
- 音频截取工具 (`audioSegmentTool`)
- 音频帧工具 (`audioFrameTool`)

## 任务类型与工具对应关系

| 任务类型 | 可用全局工具 | 专用工具 |
|---------|-------------|----------|
| 图像 | 标签工具、文本标注工具 | 矩形框、多边形、点标注、线条、立体框、关联关系、智能标注 |
| 视频 | 标签工具、文本标注工具 | 视频截取、视频帧 |
| 音频 | 标签工具、文本标注工具 | 音频截取、音频帧 |
| 文本(问答对生成) | 标签工具、问答对生成工具 | 无 |

## 特殊规则

1. **问答对生成工具限制**
   - 仅在"文本(问答对生成)"任务中可用
   - 其他任务类型无法选择此工具

2. **文本标注工具限制**
   - 在"文本(问答对生成)"任务中不可用
   - 避免与问答对生成工具混淆

3. **标签工具通用性**
   - 所有任务类型都可以使用标签工具
   - 用于添加分类标签

## 工具选择逻辑

### 图像任务
- 默认选择：矩形框工具
- 可选全局工具：标签工具、文本标注工具

### 视频任务
- 默认选择：视频截取工具
- 可选全局工具：标签工具、文本标注工具

### 音频任务
- 默认选择：音频截取工具
- 可选全局工具：标签工具、文本标注工具

### 文本(问答对生成)任务
- 默认选择：标签工具
- 可选全局工具：标签工具、问答对生成工具
- **注意**：不提供文本标注工具

## 配置说明

工具的选择和配置通过以下文件控制：

1. **`src/enums/index.ts`** - 工具枚举定义
2. **`src/constants/toolName.ts`** - 工具名称映射
3. **`src/pages/tasks.[id].edit/partials/AnnotationConfig/formConfig/index.tsx`** - 工具配置逻辑
4. **`src/pages/tasks.[id].edit/partials/AnnotationConfig/formConfig/templates/`** - 工具配置模板

## 注意事项

1. 工具的选择是基于任务类型的，确保选择正确的工具组合
2. 问答对生成工具是专门为问答对生成任务设计的，不要在其他任务中使用
3. 文本标注工具和问答对生成工具是不同的工具，用途不同
4. 所有工具都支持自定义属性配置
