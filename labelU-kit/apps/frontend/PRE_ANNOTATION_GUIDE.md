# 预标注任务功能使用指南

## 功能概述

预标注任务功能允许用户使用AI模型对图片和PDF文件进行自动预标注，提高标注效率。用户可以选择不同的任务类型和模型，上传文件后系统会自动进行预标注处理。

## 功能特性

### 1. 任务类型支持
- **图像分类**: 对图片进行分类标注
- **目标检测**: 检测图片中的目标对象
- **文本分类**: 对文本内容进行分类
- **语音识别**: 语音转文字识别
- **PDF文档OCR**: PDF文档的文字识别

### 2. 模型选择
- **ResNet-50**: 图像分类模型
- **YOLO-v5**: 目标检测模型
- **BERT-base**: 文本分类模型
- **Whisper**: 语音识别模型
- **Tesseract**: OCR识别模型
- **自定义模型**: 支持用户自定义模型

### 3. 文件上传
- 支持图片格式：JPG、JPEG、PNG、GIF、BMP
- 支持PDF文档
- 单个文件大小限制：100MB
- 支持批量上传

### 4. 任务管理
- 任务状态监控：待处理、运行中、已完成、已暂停、失败
- 进度显示：已处理样本数/总样本数
- 准确率统计
- 任务操作：暂停、继续、删除、查看结果

## 使用方法

### 步骤1：创建预标注任务
1. 在预标注任务页面点击"创建预标注任务"按钮
2. 填写任务基本信息：
   - **任务名称**: 输入任务名称
   - **任务类型**: 选择任务类型（图像分类、目标检测等）
   - **选择模型**: 选择对应的AI模型
   - **关联任务**: 选择要预标注的目标任务
   - **任务描述**: 可选，描述任务详情
   - **优先级**: 选择任务优先级（高、中、低）

### 步骤2：上传文件
1. 在文件上传区域点击或拖拽文件
2. 支持的文件格式：
   - 图片：.jpg, .jpeg, .png, .gif, .bmp
   - 文档：.pdf
3. 文件大小限制：单个文件不超过100MB
4. 可以批量选择多个文件

### 步骤3：配置模型参数
1. 在"模型配置"区域输入JSON格式的配置参数
2. 配置参数是可选的，可以使用默认配置

### 步骤4：创建任务
1. 点击"创建"按钮提交任务
2. 系统会显示创建进度
3. 创建成功后任务会出现在任务列表中

### 步骤5：监控任务状态
1. 在任务列表中查看任务状态
2. 可以执行以下操作：
   - **暂停**: 暂停运行中的任务
   - **继续**: 继续已暂停的任务
   - **查看结果**: 查看已完成任务的结果
   - **重试**: 重试失败的任务
   - **删除**: 删除任务

## 技术实现

### 前端组件
- `PreAnnotation`: 预标注任务主页面
- 文件上传组件：支持拖拽上传
- 任务列表表格：显示任务状态和操作

### API服务
- `preAnnotation.ts`: 预标注任务相关API
- 支持任务创建、状态更新、结果下载等操作

### 文件处理
- 使用FormData进行文件上传
- 支持多种文件格式验证
- 文件大小限制检查

## 注意事项

1. **文件格式**: 只支持图片和PDF文件
2. **文件大小**: 单个文件不能超过100MB
3. **任务状态**: 任务创建后会自动开始处理
4. **结果下载**: 已完成的任务可以下载预标注结果
5. **网络连接**: 需要稳定的网络连接进行文件上传
